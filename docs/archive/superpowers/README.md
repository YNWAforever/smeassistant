# Archived agent workflow evidence

This folder was `.superpowers/` at the repository root until 2026-10-20. It holds
evidence written by earlier agent-driven work: comparison and metrics captures and
the review-usage-reliability run of 2026-10-17 (`sdd/`).

Older reports in `docs/audits/` and `docs/implementation/` cite these files by their
old path. Read `.superpowers/sdd/...` in those reports as
`docs/archive/superpowers/sdd/...`. Files those reports describe as untracked were
never committed, so they are not here.

Nothing in the application, its tests or CI reads this folder.
